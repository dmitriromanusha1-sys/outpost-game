# Outpost

Стратегическая защита в реальном времени. Стройте укрепления, прокачивайте навыки и отбивайте волны врагов.

## Играть онлайн

https://dmitriromanusha1-sys.github.io/outpost-game/

## Скачать и запустить локально

Скачайте архив через кнопку «Скачать игру» в главном меню (GitHub Release), распакуйте и запустите `launch.bat`. Откроется браузер с локальной версией игры — интернет не требуется.

Либо вручную:

```bash
powershell -ExecutionPolicy Bypass -File server.ps1
```

## Структура

```
index.html      — разметка и основная игровая логика
css/            — стили
js/             — игровые системы (графика, навыки, уровни, музыка, хоткеи)
textures/       — спрайты построек, врагов, карт
music/          — фоновая музыка
```
